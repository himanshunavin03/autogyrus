# AutoDrive AI

AutoDrive AI is a custom WordPress automotive marketplace built to compete with AutoTrader-style inventory sites while differentiating through AI-powered buyer intelligence.

## Delivered in this rebuild

- Custom WordPress theme
- Custom marketplace plugin
- ACF local field groups
- Vehicle, dealer, and lead post types
- Natural-language AI search
- Future resale prediction
- Alberta winter scoring
- Maintenance forecasting
- Reliability scoring
- Insurance estimation
- VIN decode endpoint
- Dealer dashboard
- 50 vehicle sample-data seeding
- Installation, local-dev, deployment, and database docs

## Key Paths

- Theme: `app/public/wp-content/themes/autogyrus`
- Plugin: `app/public/wp-content/plugins/autogyrus`
- Docs: `docs`

## Immediate Next Step

Open WordPress admin, activate the plugin and theme, install ACF, then use the `AutoDrive AI` admin page to seed the demo inventory and add your OpenAI API key.
